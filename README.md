# 📱 Personal Portfolio App

Welcome to my **Android Portfolio App**, a modern and responsive mobile application built using **Kotlin** and **XML**. This app showcases my projects, skills, experience, and personal background — all in one elegant interface.

---

## ✨ Features

- 🎨 Clean and modern UI with CardView design
- 💼 Organized sections: About Me, Skills, Projects, Contact
- 🚀 Smooth animations (fade, scale, and more)
- 📱 Responsive layout for different screen sizes
- ⚡ Fast performance with minimal dependencies

---

## 🛠️ Built With

- **Kotlin**
- **Android XML**
- **Android Studio**
